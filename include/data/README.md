# Dataset provenance

`Flight_Price_Dataset_of_Bangladesh.csv` is the full dataset used by this lab.

- Source: [Flight Price Dataset of Bangladesh on Kaggle](https://www.kaggle.com/datasets/mahatiratusher/flight-price-dataset-of-bangladesh)
- Creator: Mahatir Ahmed Tusher
- Dataset license shown on Kaggle: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- Kaggle describes the records as synthetic.

The dataset is included for this educational project with attribution. If you
redistribute an adapted dataset, follow the license terms, including
attribution and share-alike requirements.
